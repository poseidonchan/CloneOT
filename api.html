class cloneot.CloneOTModel(adata, condition_key: str, source: str, target: str, clone_key: str | None = None, layer: str | None = None, n_top_genes: int = 2000, config: CloneOTConfig | None = None, vae_config: VAEConfig | None = None, device: str | None = None)[source]¶

Bases: object

CloneOT on an AnnData object.

Parameters:

  • adata (AnnData) – Cells of both conditions. adata.X (or adata.layers[layer]) holds raw counts or log-normalized expression.

  • condition_key (str) – Column of adata.obs with the condition of every cell.

  • source (str) – Values of condition_key for the cells before and after the perturbation.

  • target (str) – Values of condition_key for the cells before and after the perturbation.

  • clone_key (Optional[str]) – Column of adata.obs with the clone of every lineage-traced cell (NaN or empty for cells without a label). Without clone labels, CloneOT is entropic optimal transport with the squared Euclidean cost.

  • layer (Optional[str]) – Layer to use instead of adata.X.

  • n_top_genes (int) – Highly variable genes to model (Seurat v3 selection on counts, treating the two conditions as batches).

  • config (Optional[CloneOTConfig]) – Settings of CloneOT and of the VAE (defaults: the settings of the paper).

  • vae_config (Optional[VAEConfig]) – Settings of CloneOT and of the VAE (defaults: the settings of the paper).

  • device (Optional[str]) – Torch device.

Learn the representation, the transport cost and the neural map.

Parameters:

Settings of CloneOT. The defaults are the settings of the paper, shared by all simulations and single-cell tasks.

The fields of CloneOTConfig and their defaults (the settings of the paper):

@dataclass
class CloneOTConfig:
    """Settings of CloneOT. The defaults are the settings of the paper, shared by all simulations and single-cell
    tasks."""
    eps: float = 0.1                 # entropic temperature, in units of the median m of 1/2 |y - x|^2
    # dual potentials and map
    hidden: int = 128                # width of the potentials and of the map
    layers: int = 3                  # hidden layers of the potentials and of the map
    activation: str = 'silu'
    clone_embed: int = 16            # dimension of the clone embedding of the constrained potential (0: none)
    lr_potential: float = 1e-3
    batch: int = 4096                # target cells per potential step (all target cells if fewer)
    # learned cost c(x, y) = h(phi(x) - psi(y))
    cost: str = 'neural'             # 'neural' (learned) or 'euclidean' (fixed 1/2 |x - y|^2, i.e. entropic W2 OT)
    h: str = 'icnn'                  # 'icnn': g(d) + g(-d) + alpha/2 |d|^2; 'quadratic': alpha/2 |d|^2
    flows: bool = True               # neural ODE flows phi and psi (False: identity maps)
    icnn_hidden: int = 64
    icnn_layers: int = 2
    icnn_init: float = 1.            # scale of the ICNN output weights at initialization
    flow_hidden: int = 64
    flow_layers: int = 2
    flow_steps: int = 4              # Runge-Kutta steps of the flows
    lr_cost: float = 1e-3            # learning rate of h
    lr_flow: float = 1e-4            # learning rate of the flows
    cost_beta2: float = 0.99         # Adam second-moment decay of the cost
    cost_batch: int = 1024           # target cells per cost gradient
    cost_samples: int = 8            # source cells sampled per target cell from each coupling
    # schedule
    warmup: int = 500                # potential steps before the cost moves
    steps: int = 2000                # cost updates
    potential_steps: int = 5         # steps of each potential per cost update
    polish: int = 2000               # steps of the free potential at the final cost
    # neural map
    map_lr: float = 3e-4
    map_steps: int = 3000
    map_batch: int = 256             # source cells per map step
    seed: int = 0

Evaluation¶

Clone-level evaluation of predicted perturbation responses.

For every clone with predicted profiles {p_i} (one per source cell) and observed target cells {y_j}:

  • l2: distance between the predicted and the observed clone-mean expression;

  • r2: squared Pearson correlation between the two clone means across genes;

  • energy: the energy score mean ||p - y|| - 1/2 mean ||p - p'||, a strictly proper scoring rule of the predicted distribution.

The clone-specific correlation removes the response that all clones share: it correlates the predicted and observed deviations of every clone mean from the average over clones, across all clones and genes.

Datasets¶

The two simulated examples of the paper.

In both, source and target are unpaired samples of two classes, and optimal transport with the squared Euclidean cost sends cells to the wrong class:

  • t_shape: the T-shape example of Howard et al. (2024). A vertical bar on the left moves to the right and a horizontal bar on top moves down. Cells come in clones of sister cells at one position of a bar.

  • rotated_moons: the task of OT-SI (Liu et al., 2020). The target is the two moons rotated by 90 degrees, and the only lineage is which source moon corresponds to which rotated moon.

Each function returns a dictionary with the source and target cells, their classes (source_class, target_class), clone labels and the true fate fate(x) of a source cell.

cloneot.datasets.watermelon(data_dir: str = 'data', download_files: bool = True)[source]¶

Watermelon lineage tracing of PC9 lung cancer cells treated with osimertinib (Oren et al., Nature 2021; GEO GSE150949).

Cells were profiled before treatment (day 0) and at days 3, 7 and 14; day-14 persister cells were sorted by a proliferation-history reporter into cycling, moderate and non-cycling fractions. The first call downloads 125 MB from GEO and caches <data_dir>/watermelon.h5ad.

Returns:

  • AnnData with raw counts in X and obs columns clone (single-barcode clone label, NA otherwise),

  • lineage_block, day, condition (‘day0’, ‘day3’, ‘day7’, ‘day14’), fraction (‘cycling’, ‘moderate’,

  • ’non-cycling’ or ‘unsorted’ for day 14; ‘unsorted’ before), sample and replicate.

cloneot.datasets.holdout(adata, clone_key: str, condition_key: str, fraction: float = 0.2, unit: str = 'cells', min_cells: int = 2, seed: int = 0)[source]¶

Boolean mask of held-out cells for evaluation.

  • unit='cells' (seen clones): a fraction of the cells of every clone with at least min_cells cells in each condition is held out, so the test clones also appear in training.

  • unit='clones' (unseen clones): all cells of a random fraction of the clones are held out.

Cells without a clone label are never held out.

Return type:

ndarray
